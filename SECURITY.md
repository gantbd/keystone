# Security policy

Report suspected vulnerabilities privately to the repository owner. Do not
open a public issue containing credentials, private keys, source content,
workspace paths, socket paths, checkpoint contents, or other sensitive
material.

Keystone is pre-release and source-distributed from pinned Git commits. There
is no supported release series or security-update branch yet. Reports should
identify the full commit revision and affected crate or qualification profile.

The presence of a mechanism in this workspace is not a security or production
qualification claim. The exact status and evidence for each named profile are
recorded in `qualification-status.json`; documented nonclaims continue to
apply even when a profile is classified as qualified.
